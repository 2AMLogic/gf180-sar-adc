## Why this record exists

**The document behind T1 item 8 changed.** Issue #393 drove the four
governing extracted ADC decks through a real `V_DD` source network at the edge
of DR-0036's proposed budget (`Z_vdd = 3 Ω`, `C_dec = 40 nF`, one shared pin).
Each deck ran as paired same-commit arms (`800bf53`). The new evidence
is in `sim/vdd-full-pvt/README.md` and in the eight new `sim/` records it
cites. `sim/characterization-summary.md`'s `Supply` row now carries that
result, and the document gained a fifth Freshness partial-update entry (#393).

`signoff/run_signoff.py --check` re-hashes the wrapped document on every pull
request. It turned PR #407's `headless checks` job red on exactly that edit
(`sha256:0463bbff…` in CI against the pinned `sha256:15960654…`). That is why
this is a re-mint and not an edit. The document's bytes moved once more when
the #393 Freshness entry was added, so the pin is now:

```
sha256:15960654…36d5233b   ->   sha256:ca0986b1…84869d18
```
