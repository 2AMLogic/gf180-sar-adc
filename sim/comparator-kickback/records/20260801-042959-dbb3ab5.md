- **Note**: THE PREAMP IS THE MITIGATION, AND THIS IS THE MEASUREMENT THAT SAYS SO. DR-0007 chose a static preamplifier ahead of the StrongARM latch partly because it makes the input stage unidirectional: the regenerating nodes, which swing the full 3.3 V rail, are two stages away from the CDAC top plate instead of being capacitively coupled to it through the latch input pair's C_gd. This record is the evidence for that claim, not an assertion of it -- a bare StrongARM's kickback at the same devices would be visible in the same measurement.
- **Note**: THE TOP PLATE IS FLOATING, DELIBERATELY. Biasing the inputs from ideal voltage sources would restore the injected charge instantly and report ~0 kickback no matter how bad it was; that is the standard way this measurement is faked. Here the input is 8.83 pF (spec/cdac-sizing-memo.md S6's C_side) fed through 1 Gohm, so the RC is 8.8 ms against a 62.5 ns bit cycle -- the bias network sets the operating point and then does nothing.
- **Note**: SAMPLING-SWITCH AND BOTTOM-PLATE DYNAMICS ARE NOT MODELLED HERE. The top plate is a lumped capacitance, not the real 512-position array with its switch resistances; sim/cdac-bit-settling/ (issue #8) owns that. Combining them would confound kickback with settling. The lumped model is the conservative direction for the residual kick (no path to ground at all) and the optimistic one for the peak excursion (no series resistance), which is why the peak is reported separately rather than folded into the claim.
- **Note**: MISMATCH IS OFF (PDK default sw_stat_mismatch = 0). Kickback and offset are separable effects and are budgeted separately; a mismatched instance would add its offset to the measured top-plate displacement and make neither number attributable.
- **Note**: NUMERICAL RESOLUTION IS PART OF THIS MEASUREMENT. ngspice's default voltage tolerance (vntol = 1 uV) is COARSER than the residual kickback this topology produces: run at defaults, the deck reports differential kicks of exactly -1, 0 or +1 uV -- the solver's own granularity, not the circuit's. The tightened tolerances above (vntol = 1 nV, reltol = 1e-4) push the numerical floor three decades below the reported values so that a small number is a measurement rather than a rounding artefact. Any future re-run that drops them is not comparable with this record.
