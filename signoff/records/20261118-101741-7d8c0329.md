## Reproduce

```bash
python3 -I signoff/run_signoff.py --check
```

re-derives every input behind this verdict from the committed tree; CI runs it
on every pull request (`npm run check:signoff`). To re-mint from scratch:

```bash
klt signoff --format json -o signoff/reports/<record-id>/signoff.json \
  --manifest signoff/gf180-sar-adc.manifest.json
python3 signoff/run_signoff.py --regen
```

under the grader commit `signoff/toolchain.json` pins.
