# Decode-bank shared-S/D fold candidate 20261120-191014-2dd7403e (issue #936)

Append-only evidence record for the candidate built by
`../gen_bank_fold_candidate.py` into `../bank-fold-2x/`. The accounting
and ranking that selected this lever are in
`../../economy/records/20261120-191014-2dd7403e.md` (Part 3: rank 1,
upper bound 13,434.10 um^2). #668 named the lever and did not test it
("a real shared source/drain fold"); this record is the measured test.

**Headline: measured saving 13,434.100 um^2 (-10.26%), DRC clean at the
pinned deck, LVS match on both streams, production stream untouched.**
The Area row stays FAIL (0.117414 mm^2 > 0.1 mm^2); nothing is adopted
here.

## The candidate

One change, stated at both levels:

- **Netlist** (`bank-fold-2x/adc_top.candidate.spice`, generated from
  `design/adc-top/adc_top.spice`): the four BANK T-gate lines of
  `adc_cdac_cell` (Xsi/Xsr/Xsh/Xsl) call a new `adc_tgate_f` whose PMOS
  is two parallel `wp=10u` devices instead of one `wp=20u`. The
  top-plate switch's own `adc_tgate` is untouched (its row is not
  height-critical; folding it would only push the comparator right).
  Flattened device count: 296 -> 368 MOS (the +72 are the 2 sides x
  9 cells x 4 T-gates x 1 extra PMOS finger).
- **Layout** (`gen_adc_top.build(..., bank_fold_shared_sd=True)` ->
  `lib/place.draw_devices(..., fold_shared_sd=True)`, both added in this
  change and default-off): consecutive identical PMOS twins are drawn as
  one folded pair — the second finger's island ABUTS the first's (no
  COLUMN_GAP) and is MIRRORED in X, so the diffusion shared at the
  abutment carries the same net on both sides. Measured on the drawn
  stream: all 36 pairs per bank merge into single 4,960 nm islands
  (Comp island census: baseline `{2480x36 @10um, 2480x36 @20um, ...}` ->
  candidate `{4960x36 @10um, 2480x36 @10um, ...}`), i.e. real shared
  source/drain, not two adjacent devices.

One secondary geometry change is forced by the fold and rides the same
flag: the bank row's right edge moves past the comparator's left edge
(row_x1 434.66 -> 523.94 um), so the far hop of the `vdd`/`vss`/`vcm`
bridge — whose corridor is derived from that edge — lands inside the
comparator's Comp span, where a Poly2 strap is correctly refused
(`geo.stitch`'s parasitic-device guard fired during bring-up: "corridor
at x=532240 crosses existing Comp"). `vcm`'s FAR hop joins `vdd`/`vss`
on Metal2 under the flag (the same property that made Metal2 the answer
for the supplies in #378: it crosses Comp without connecting); the near
hop inside `SWITCH_CMP_GAP` stays Poly2. The reference-net argument for
Poly2 (#378's comment) is about strap resistance, not correctness.

## Measured results

`klt economy` (0.8.0 + klayout 0.30.12, measurement) on
`bank-fold-2x/adc_block.gds` (`reports/adc_block.economy.json`):

| | baseline | candidate | delta |
|---|---|---|---|
| bbox um | 671.705 x 194.800 | 671.705 x 174.800 | -20.000 height, width unchanged |
| bbox um^2 | 130,848.134 | 117,414.034 | **-13,434.100 (-10.26%)** |
| drawn um^2 | 66,769.6204 | 65,156.912 | -1,612.708 |
| utilization | 0.510283 | 0.554933 | +0.044650 |
| decode bank um | 480.66 x 32.46 | 532.77 x 22.46 | row height 21.30 -> 11.30 |
| right dead column um^2 | 11,297.88 | 9,808.18 | shrinks with the height it crosses |

The saving lands exactly on the predicted term: -20.000 um of stack
height (two banks' rows, 21.30 -> 11.30 um each — the wp=20u PMOS column
was the only thing above the 11.30 um the 10 um NMOS + tap strip force)
x the unchanged 671.705 um width. The width cost (+89.28 um of row,
measured) is absorbed inside the block: the bank bbox (532.54 um right
edge) stays 55.2 um clear of the comparator's right edge (587.76), and
the block width is set by neither — it is the SAR reserve column
(economy record Part 1). `adc_top` (the no-comparator LVS stream)
measures 653.3 x 174.8 = 0.11420 mm^2; its width grew +18 um because
that stream has no reserve column and its right edge follows its own
straps — recorded, not load-bearing.

## Ratified rows at risk (named, with numbers — not re-simulated here)

- **Settling / switch R_on** (`sim/cdac-bit-settling/`,
  `sim/device-switch-ron/`): parallel W per T-gate unchanged
  (20u = 2 x 10u), so R_on moves only through junction parasitics:
  S/D junction area per pair is preserved (2 x 1100x20000 ->
  2 x 1100x10000 + 2200x10000 nm^2) while its perimeter drops (the
  shared edge is interior); a second-order C_jc change that only PEX
  can quantify.
- **Mismatch**: all 36 bank T-gates fold identically (the bank is
  unit-weighted, m= devices); the matching-critical CDAC arrays and
  their dummy ring are untouched.
- **Bank parasitics** (`layout/adc-top/parasitics/`): the shared node
  carries two riser columns on one diffusion (same net, lower R); the
  removed per-row 20 um column also removes ~1,600 um^2 of drawn
  well/implant. PEX totals will move; the droop budget's verdicts are
  re-taken at adoption.
