## Disposition

**The bespoke 2-endpoint deck's own methodology is responsible for record
`20260805-163000-e8017f2`'s -0.55 LSB extracted-vs-schematic delta. It is a
measurement artifact, not a parasitic effect.**

- Record `20260805-163000-e8017f2` (bespoke deck, extracted core) and record
  `20260805-203322-3b6d7b7` (manifest-driven, extracted core) are **both left
  unedited** -- `sim/` is append-only (`sim/README.md`, "Append-only rule").
  Neither number is wrong as a *measurement of what it measured*; this record
  adjudicates which of the two reflects a real physical effect.
- The evidence: a core with **zero layout parasitics** (schematic `_core()`),
  run through the bespoke deck's identical 2-endpoint stimulus and error-node
  instrumentation, reads **-2.55 LSB, not -2.00 LSB** -- reproducing the
  "extracted" reading almost exactly (mean delta +0.0027 LSB, three orders of
  magnitude tighter than the -0.55 LSB gap under adjudication) with no
  parasitics anywhere in the circuit to cause it.
- The mechanism `sim/extracted-delta-summary.md` Sec 4.3 already proposed
  (before this control existed) is confirmed directly rather than left as
  "best-supported, not closed": the two decks differ in how the input reaches
  transition 1023 (a ~1022 LSB step in one 10 ns ramp vs the manifest's <=126
  LSB ladder steps), both allowing the same single 1000 ns conversion
  (`INL_CONV_PER_POINT = 1`) to settle before the decision -- an
  incompletely-acquired near-full-scale input step through the DR-0013 RC
  input network, not a top-plate parasitic gain term.
- **The number this document's downstream consumers (including #53's
  top-plate-parasitic gain-error adjudication) should use for the extracted
  converter-level gain error remains -2.0081 LSB worst (`ff_125c_3.63v`),
  delta +0.006 LSB vs schematic** -- record `20260805-203322-3b6d7b7`'s
  manifest-driven reading, now confirmed rather than merely preferred. The
  extracted-core disagreement between `163000-e8017f2` and `203322-3b6d7b7`
  does NOT need its own follow-up investigation: this control shows the
  *deck*, not the *core*, is what changed between them.
- No spec line or ratified check window is touched by this record
  (CLAUDE.md: no spec relaxation). `gain_err_lsb` remains an unbudgeted,
  informational term per `spec/testbench-suite-memo.md` Sec 3.5.
