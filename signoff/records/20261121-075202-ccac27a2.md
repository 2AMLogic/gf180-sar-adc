## What this `met` does NOT claim

- **No setup/hold violation checking.** Icarus implements SDF delays
  (IOPATH/INTERCONNECT) but not SDF `TIMINGCHECK` sections — klt reports
  every dropped class per corner (`timingcheck`, `iopath_cond_expression`,
  `iopath_ifnone_edge_modpath`, `zero_delay_*`) in each response. A genuine
  timing failure still surfaces as a functional failure the bench catches;
  slack numbers remain #486's OpenSTA evidence.
- **The SDF inherits the qualified SPEF's extraction-model limits unchanged**
  (lumped-star, 0-ohm legs, no wire resistance; one nominal extraction at all
  five Liberty corners; ideal clock). The `INTERCONNECT` triplets in the SDFs
  are correspondingly ~0: the wire *capacitance* slows the drivers (in the
  IOPATH delays), the 0-ohm legs add no wire delay. This record adds
  annotation coverage, not extraction fidelity.
- **No mutation testing on the gate-level leg** — `options.sdf` rejects
  `--mutations` (klt design decision); the suite's sensitivity rests on
  #642's nine-mutant RTL record, which is unchanged.
- **Corner selection inside one SDF is cosmetic** — each file's
  min:typ:max triplets are uniform (written from that Liberty corner's
  single-condition arcs), so `options.sdf.corner: "typ"` selects the same
  delays any member would.
