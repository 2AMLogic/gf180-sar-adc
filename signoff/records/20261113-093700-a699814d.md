## Why this record exists

The pinned-PDK re-bind (#514, merged as #517: open_pdks `c6d73a3` ->
`f6eeac7`) changed `gf180mcu_fd_sc_mcu7t5v0`'s SPICE library from the
6V-oxide device to the 5V-oxide one — the old library binds 4809
`*fet_06v0` instances, the new one 4810 `*fet_05v0`. The seven gate-level
testbench decks inline that library text, so every one of them still
described the OLD standard cells. They were regenerated under `f6eeac7`
(`python3 design/sar-logic/flow/gen_sar_ctrl_gates_tb.py`, commit
`a699814d`); the diff is device-name-only, all 1148 changed lines a
`*fet_06v0` -> `*fet_05v0` swap with every `W`/`L` unchanged.

Item 9 attests those decks' bytes, so its envelope and pins had to move with
them. The same pass corrected the stale open_pdks revision that both item-9
inventories still declared.
