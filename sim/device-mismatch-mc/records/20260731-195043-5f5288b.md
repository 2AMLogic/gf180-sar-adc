- **Note**: sw_stat_mismatch is set in the NETLIST FRAGMENT, not in the manifest's params block. The harness emits manifest params ahead of the model includes and design.ngspice sets sw_stat_mismatch = 0, so a manifest param would be silently overridden and the whole Monte Carlo would collapse to sigma = 0. The sig_n_a_mv lower-bound check is the guard against that failure mode recurring.
- **Note**: PAIR vs SINGLE-DEVICE CONVENTION. fets_mm applies mis_vth = agauss(0, 0.7071*par_vth*1e-6/sqrt(L_eff*W_eff), 1) to EACH device independently. The 1/sqrt(2) means par_vth is A_Vt in the pair convention: sigma(dV_th) between two matched devices = A_Vt/sqrt(W_eff*L_eff), and a single device's own sigma is A_Vt/sqrt(2*W_eff*L_eff). Everything reported here is the PAIR sigma. #9 must not apply the pair number to a single device.
- **Note**: EFFECTIVE AREA, not drawn area. L_eff = L - 0.15 um and W_eff = W + 0.1 um (par_l = 1.5e-7, par_w = -1e-7 in fets_mm). At L = 0.28 um the effective length is 0.13 um, less than half the drawn value, so using drawn area to scale A_Vt would understate mismatch by ~45 % at minimum length. The avt_* multipliers in this manifest are sqrt(W_eff*L_eff) for each geometry: 2.929590, 1.486607, 6.235784.
- **Note**: SUBTHRESHOLD BIAS IS THE EXTRACTION METHOD. Each device is diode-connected at I_d/(W/L) = 1 nA. There sigma(dV_gs) = sigma(dV_th) to within 0.1 % in quadrature, because the current-factor mismatch (par_k) enters only through n*kT/q*sigma(dbeta/beta) ~ 0.08 mV against ~2.4 mV. par_k is therefore NOT characterized by this record; a strong-inversion companion would be needed for that, and #9 should treat beta mismatch as uncharacterized here.
- **Note**: WHY THE FULL PROCESS AXIS IS SWEPT ANYWAY. par_vth lives in the fets_mm subckt wrapper, not in any corner .lib section, so A_Vt is corner-independent by construction and a tt-only run would have been a defensible subset. - **Note**: BETA (CURRENT-FACTOR) MISMATCH IS NOT CHARACTERIZED HERE — see sim/device-characterization-report.md § Gaps. The fets_mm section also carries par_k (0.007008 NMOS, 0.002833 PMOS) applied as mulu0 = 1 - mis_k*sw_stat_mismatch, but this testbench biases deliberately in deep subthreshold so that sigma(dV_gs) IS sigma(dV_th); the beta term contributes ~0.1 % in quadrature there and is not separable from the threshold term. Extracting it would need a strong-inversion companion pair and a quadrature subtraction against this record's numbers. #9 should treat par_k as a model-card value with model-card provenance, not as something measured here.
